# Mapa de clientes

App web de un solo archivo (`index.html`) para organizar visitas a clientes por zona, planificar rutas y registrar visitas, sincronizada con una planilla de Google.

- `index.html`: la app (se publica con GitHub Pages).
- `apps-script/script-planilla.gs`: el script que va en la planilla de Google (Extensiones → Apps Script).

Los datos (clientes, link del script) no están en este repositorio: se guardan en cada dispositivo y en la planilla.
